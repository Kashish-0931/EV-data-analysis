# Electric Vehicle (EV) Adoption & Socio-Economic Correlation Analysis

##  Project Overview
This data science project examines the intersection of regional demographics, economic health metrics (such as state-level Unemployment Rates), and political alignments. The objective is to identify the underlying socio-economic drivers and infrastructure barriers that influence Electric Vehicle (EV) market share and adoption curves across the United States.

##  Repository Structure
- `EV_SocioEconomic_Analysis.ipynb`: Main Jupyter Notebook containing the full data pipeline, statistical transformations, and Seaborn visualizations.
- `ev_state_data.csv`: Cleaned dataset containing state-level economic indicators, political landscape data, and EV infrastructure metrics.

##  Tech Stack & Libraries
- **Language:** Python 3
- **Environment:** Anaconda / Jupyter Notebook
- **Data Engineering:** Pandas, NumPy
- **Statistical Visualization:** Seaborn, Matplotlib

##  Analytical Framework & Core Insights
1. **Socio-Economic Data Auditing:** Structured a robust data inspection framework across 14 multi-variable features to guarantee zero data duplication and ensure baseline statistical consistency.
2. **Economic Trend Mapping:** Engineered conditional distribution plots (`sns.histplot`) to map variance trends in state unemployment figures, directly correlating consumer spending capabilities with localized green energy adoption thresholds.
3. **Policy & Infrastructure Evaluation:** Correlated state-level political alignments against charging station density metrics to uncover how localized public policies accelerate or bottleneck regional EV fleet growth.

##  How to Run Locally
1. Clone this repository to your local machine.
2. Ensure you have the **Anaconda Distribution** installed.
3. Launch Jupyter Notebook, open `EV_SocioEconomic_Analysis.ipynb`, and execute the cells sequentially to reproduce the visual analysis.
